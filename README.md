# AI LaTeX Fixer

A pure-Python library to repair common LaTeX and math formatting errors generated by LLMs (AI).

## Features

- **Delimiter Normalization**: Converts mixed `$`, `$$`, `\(`, and `\[` to standard LaTeX delimiters.
- **Backslash Repair**: Automatically adds missing backslashes for common LaTeX commands (e.g., `lambda` -> `\lambda`).
- **Delimiter deduplication**: Fixes over-escaped delimiters like `\\(` into `\(`.
- **Intelligent Wrapping**: Detects bare math tokens like `x_i` or `alpha_L` and wraps them in inline math delimiters.
- **Anki Support**: Specifically handles Anki's `<anki-mathjax>` tags.

## Usage

```python
from latex_fixer import fix_latex

text = "The value of lambda is x_i."
fixed = fix_latex(text)
print(fixed) 
# Output: "The value of \(\lambda\) is \(x_i\)."
```

## Why this exists?

LLMs are great at generating content but often inconsistent with LaTeX syntax. They might:
- Forget the backslash before a command.
- Mix different types of delimiters in the same sentence.
- Return "bare" math without any delimiters.
- Double-escape backslashes when returning JSON.

This library provides a robust set of regex-based rules to sanitize AI output for clean rendering in MathJax or LaTeX.
